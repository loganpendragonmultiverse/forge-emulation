# Contributing

Contributions should be narrowly scoped, tested, and compatible with the 1.0 product boundary. Start with an issue for behavior changes. Do not submit copyrighted game data, scraped artwork, telemetry, download catalogs, or unverified core binaries.

Run the commands in `TESTING.md` before opening a pull request. Core changes must include provenance and corresponding source as described in `DEVELOPMENT.md`.

By contributing, you agree that your contribution is licensed under GPL-2.0-or-later.
